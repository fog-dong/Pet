## 1. 目标与范围

- 统一角色、宠物、场景、UI 的视觉语言，保证“治愈、可信、不幼稚”。
- 给出可交付的资产规格、命名、格式与验收清单。
- 提供买量素材方向，确保 3 秒内可看懂冲突。
- 输出风格关键词、禁止项、色板、交付表与 5 条参考提示词。

不包含：具体分镜脚本、投放预算、平台素材审核细则（以平台为准）。

- 02 MVP 内容量（20 品种、50 装饰、12-15 病例）。
- 06 图鉴卡字段与分享卡需求。
- 15 包体、图集与性能限制。

## 2. 风格定位

| 维度 | 定义 |
|---|---|
| 核心词 | 温暖、治愈、手绘、绘本、柔和、可信 |
| 参考感受 | 儿童绘本 + 轻水彩 + 圆润卡通 |
| 不做 | 写实医疗、3D 渲染、暗黑、恐怖、过度女性化粉色 |
| 情绪 | 忙碌但不焦虑；有困难但不残忍 |
| 视角 | 2D 正交/轻微俯视，竖屏构图 |

**风格关键词（英文，供沟通与提示词）：**

```text
2D hand-drawn mobile game art, warm healing storybook style, soft gouache texture,
rounded shapes, gentle morning light, muted pastel palette, cozy small-town clinic,
clean silhouettes, subtle paper grain, friendly rounded UI, no text
```

## 3. 禁止项（硬性）

- 不出现写实手术、真实医疗器械品牌、针头刺入皮肤的特写。
- 不出现血液、伤口特写、骨折透视、动物痛苦挣扎。
- 不出现虐待、遗弃过程的直接描绘；遗弃只用“雨天纸箱”等含蓄表达。
- 不使用真实宠物照片、真实病历、真实医生形象。
- 不做恐怖、阴暗、高对比血腥色调。
- 不在图内生成文字（文字由 UI 层排版，避免乱码与侵权）。
- 不使用未授权 IP、明星形象、品牌Logo。

## 4. 色彩规范

| 用途 | 色值（建议） | 占比 | 说明 |
|---|---|---|---|
| 主背景 | `#F7EFE3` 奶油米 | 60% | 温暖、低刺激 |
| 辅助 | `#A8C3A0` 鼠尾草绿 | 20% | 治愈、自然 |
| 强调 | `#D98E73` 陶土橙 | 10% | 按钮、提示 |
| 辅助蓝 | `#A9C7D9` 雾蓝 | 5% | 医疗感（轻） |
| 文字 | `#4A3F35` 深棕 | 5% | 对比度足够 |

**要求：**

- 文字与背景对比度 ≥4.5:1（正文）。
- 危重状态用低饱和暖红 `#C97B6E`，不用高亮血红。
- 夜晚场景降低饱和度，不用纯黑。

## 5. 角色与宠物规范

### 5.1 人物

| 项 | 规格 |
|---|---|
| 比例 | 2.5-3 头身，圆润，弱化性别特征 |
| 三视图 | 正/侧/背，统一 2048×2048 画布 |
| 表情 | 中性、微笑、担心、惊喜、疲惫、欣慰 6 种 |
| 服装 | 简洁医护围裙/针织衫，无真实医院标识 |
| 动作 | 待机、行走、蹲下、抚摸、记录 5 组 |

### 5.2 宠物

| 项 | 规格 |
|---|---|
| 品种 | MVP 20 种（猫/狗为主，少量兔/鸟） |
| 三视图 | 正/侧/背，统一画布与站姿基线 |
| 表情 | 警惕、放松、亲近、疼痛（卡通化）、开心、困倦 |
| 动作 | 待机、走动、蹭手、趴卧、被抱起 5 组 |
| 特征 | 每品种保留 2-3 个识别特征（耳型、花纹、尾型） |

**注意：** “疼痛”表情只用耷耳、眯眼、低头表达，不画伤口与泪水特写。

## 6. UI 规范

| 项 | 规格 |
|---|---|
| 设计分辨率 | 750×1334（竖屏），适配安全区 |
| 栅格 | 8px 基准，间距 8/16/24 |
| 圆角 | 卡片 16px，按钮 24px |
| 按钮最小点击区 | ≥80×80px |
| 字体 | 思源黑体/系统字体，标题 40-48px，正文 26-30px |
| 图标 | 线性+面性结合，统一 2px 描边 |
| 九宫格 | 弹窗、按钮、资源条必须九宫格 |
| 动效 | 200-300ms，缓入缓出，不做强闪烁 |

**UI 情绪：** 资源不足用暖色提示，不用红色警告；失败文案温和，避免责备。

## 8. 买量素材方向

### 8.1 3 秒冲突结构

```text
0-1s：雨夜纸箱里发抖的小猫（含蓄、无伤口）
1-2s：玩家抱起它冲进亮着灯的小医院
2-3s：治疗/喂药/它第一次蹭手（卡通化）
3s+：真实玩法画面 + “开一家温暖的小医院”
```

**要求：**

- 前 3 秒必须有明确冲突与情绪钩子。
- 真实玩法画面占比 ≥50%，不虚构不存在的玩法。
- 不承诺“真实救助”“公益捐赠”，不使用虚假医疗效果。
- 字幕大、对比强，静音也能看懂。
- 每轮至少 3 版：救助情绪版、经营成长版、宠物可爱版。

### 8.2 素材禁区

- 不展示血腥、伤口、虐待过程。
- 不使用“点击就救它”“不玩就会死”等道德绑架文案。
- 不使用虚假红包、虚假提现、虚假中奖。
- 不使用未授权音乐与字体。
