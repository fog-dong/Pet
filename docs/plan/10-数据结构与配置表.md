> **说明**：本文为云数据库集合与配置表的**建议设计**，不含已建集合。所有字段名、类型、索引均为建议，落地前需与客户端、服务端共同评审。金额统一以**分（fen）**为单位存储，禁止浮点。

## 1. 目标与范围

- 把 09 号文件中的核心集合转成可建表的字段设计；含冻结新增的 `pets` 与 `leaderboard`，共 9 个核心集合。
- 定义索引、唯一约束、数据保留与金额规范。
- 补齐病例、商品、广告位、活动四类配置表字段。
- 定义配置版本化与灰度发布方式。

不包含：具体业务公式（见 04/05/07）、云函数实现（见 09）、埋点分析口径（见 13）。

### 1.1 输入依赖

- 05 资源字段与初值。
- 06 图鉴卡、助力日志字段。
- 09 云函数与幂等键约定。
- 11/12 广告位、订单与金额字段。
- 缺失时：字段冲突以 09 的接口契约为准，先改本文再改代码。

## 2. 设计原则

| 原则 | 说明 |
|---|---|
| 金额用分 | 所有金额字段为 `int`，单位分，禁止小数 |
| 时间用毫秒时间戳 | 字段后缀 `At`，统一 `int64` |
| 软删除 | 关键业务数据用 `status` 标记，不物理删除 |
| 服务端写入 | 客户端不直接写数据库，只读必要字段 |
| 索引先行 | 高频查询必须建索引，避免全表扫描 |
| 配置版本化 | 配置带 `version` 与灰度标签，可回滚 |
| 最小冗余 | 允许少量冗余字段用于查询，但需注明来源 |

## 3. 核心集合

### 3.1 `users`（用户账户）

| 字段 | 类型 | 说明 | 索引/约束 |
|---|---|---|---|
| `_id` | string | 文档 ID | 主键 |
| `openid` | string | 微信 openid，服务端写入 | 唯一索引 |
| `unionid` | string? | 若有 | 普通索引 |
| `nickname` | string? | 用户授权后写入 | — |
| `avatarUrl` | string? | 用户授权后写入 | — |
| `createdAt` | int64 | 注册时间 | — |
| `lastLoginAt` | int64 | 最后登录 | 普通索引 |
| `lastScene` | string | 最近来源场景 | — |
| `status` | enum | active/banned/deleted | 普通索引 |
| `revision` | int | 存档版本号，单调递增 | — |
| `resources` | object | 资源摘要（见下） | — |
| `reputation` | int | 口碑值 | — |
| `flags` | object | 新手引导、活动标记等 | — |

**`resources` 子字段（建议）：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `coins` | int | 金币 |
| `hearts` | int | 爱心 |
| `beds` | int | 床位数（当前上限） |
| `medicine` | object | 各药品数量，如 `{ "antibiotic": 3 }` |
| `trainingPoints` | int | 培训点 |
| `fragments` | int | 图鉴碎片 |
| `updatedAt` | int64 | 资源最后变更时间 |

**约束：**

- `resources.coins/hearts/medicine[*]` 不得为负；服务端写入前校验。
- `resources` 只由 `syncCaseResult` 在事务内按服务端配置入账（`login` 首次建号除外）；`saveGame` 忽略客户端快照中的 `resources`（W15-1/D15）。
- `revision` 只能递增，`saveGame` 拒绝回退（见 09）。

| `storyId` | string | 专属故事 ID | — |

| 字段 | 类型 | 说明 | 索引/约束 |
|---|---|---|---|
| `_id` | string | 文档 ID | 主键 |
| `adoptionId` | string | 领养关系 ID | 唯一索引 |
| `cardId` | string | 图鉴卡展示 ID | 唯一索引 |
| `openid` | string | 领养人 | 组合索引 `openid + adoptedAt` |
| `petId` | string | 关联 `pets.petId` | 唯一索引（有效关系） |
| `adoptedAt` | int64 | 领养时间 | — |
| `isFirstAdoption` | bool | 是否首次获得该物种 | — |
| `sharedCount` | int | 自愿分享次数 | — |

**约束：** 只存领养关系，不冗余 `petSpecies/petName/rarity/storyId/careScore`；展示时按 `petId` 读 `pets`，按 `pets.caseSessionId` 读病例记录；`cardId` 与 `petId` 一对一；`isFirstAdoption` 由服务端按物种判定。

### 3.6 `ad_events`（广告事件）

| 字段 | 类型 | 说明 | 索引/约束 |
|---|---|---|---|
| `_id` | string | 文档 ID | 主键 |
| `idempotencyKey` | string | 统一幂等键，格式 `openid:adSessionId` | 唯一索引 |
| `adSessionId` | string | 广告会话 ID | 普通索引（业务查询） |
| `openid` | string | 归属用户 | 组合索引 `openid + createdAt` |
| `adUnitId` | string | 广告位 ID | 组合索引 `adUnitId + createdAt` |
| `scene` | string | 场景，如 `case_result` | 普通索引 |
| `isEnded` | bool | 是否完整播放 | — |
| `reward` | object | `{ type, amount }` | — |
| `platformDate` | string | 平台报表日期 `yyyy-MM-dd` | 组合索引 |
| `createdAt` | int64 | 事件时间 | TTL 候选 |
| `reconciled` | bool | 是否已对账 | 普通索引 |

**约束：** `idempotencyKey` 唯一（`openid:adSessionId`），重复上报返回首次结果；`adSessionId` 保留业务查询；`isEnded=false` 不发奖但仍记录，用于漏斗分析。

| 字段 | 类型 | 说明 | 索引/约束 |

| `skuId` | string | 商品 ID | 普通索引 |
| `amountFen` | int | 金额（分），服务端读取 | — |

| `transactionId` | string? | 平台交易号 | 唯一索引（稀疏） |

### 3.8 `config`（配置）

| 字段 | 类型 | 说明 | 索引/约束 |
|---|---|---|---|
| `_id` | string | 文档 ID | 主键 |
| `configKey` | string | 配置键，如 `cases`、`skus` | 组合唯一 `configKey + version` |
| `version` | int | 版本号，单调递增 | 组合唯一 |
| `payload` | object | 配置内容 | — |
| `status` | enum | draft/active/archived | 普通索引 |
| `grayTags` | array | 灰度标签，如 `["ios","v1.2"]` | — |
| `grayPercent` | int | 灰度比例 0-100 | — |
| `effectiveAt` | int64 | 生效时间 | — |
| `createdBy` | string | 操作人 | — |
| `createdAt` | int64 | 创建时间 | — |

**版本化规则：**

- 同一 `configKey` 同时只有一个 `active` 版本。
- 发布新版本 = 新建文档 + 切换 active，不原地改。
- 回滚 = 将上一版本置为 active，保留历史 ≥10 个版本。
- 客户端携带当前版本请求，服务端返回最新可用版本与是否强制更新。

### 3.9 `leaderboard`（排行榜快照，冻结新增）

| 字段 | 类型 | 说明 | 索引/约束 |
|---|---|---|---|
| `_id` | string | 文档 ID | 主键 |
| `type` | enum | reputation/collection/weekly | 组合唯一 `type + period + openid` |
| `period` | string | `all` 或周标识，如 `2026-W44` | 组合唯一；组合查询 `type + period + score` |
| `openid` | string | 用户 | 组合唯一；组合查询 `openid + type` |
| `score` | int | 榜单分值 | 组合查询 `type + period + score`（降序） |
| `rank` | int? | 服务端计算名次，可空 | — |
| `updatedAt` | int64 | 更新时间 | 组合索引 `type + period + updatedAt` |

**约束：** 只由服务端写入，客户端只读；同一 `type + period + openid` 唯一；榜单按 `score` 降序、`updatedAt` 升序取前 N；周榜换期不删历史，过期后归档。

### 3.10 辅助日志（不计入 9 个核心集合）

| 集合（建议） | 关键字段 | 用途 | 保留 |
|---|---|---|---|
| `assist_logs` | `helperId`、`targetId`、`date`、`resourceType`、`createdAt` | 助力幂等与风控 | 90 天 |
| `delivery_logs` | `orderId`、`skuId`、`items`、`operator`、`createdAt` | 发货与退款对账 | 3 年 |

**说明：** 若云开发配额紧张，可先写入云开发日志并用唯一索引键去重；但支付发货日志必须可查询。

## 5. 数据保留策略

| 集合 | 保留 | 说明 |
|---|---|---|
| `users` | 长期 | 注销后脱敏保留 90 天再删除 |
| `pets_cases` | 12 个月 | 超期归档或聚合后删除 |
| `hospital_state` | 长期 | 随用户 |
| `pets` | 长期 | 宠物长期状态，领养后随用户 |
| `adoptions` | 长期 | 图鉴关系核心数据 |
| `ad_events` | 90 天 | 超期聚合到日报后删除 |
| `orders` | 3 年 | 财务合规要求，按法务确认 |
| `config` | 长期 | 保留历史版本 |
| `leaderboard` | 长期 | 周榜历史可归档 |
| 日志 | 30 天 | 脱敏后存储 |

**要求：** 删除策略需支持按 `openid` 级联删除（用户注销）；财务数据删除需法务确认。

## 9. 验收标准

- 服务端可仅凭本文建集合、建索引，无需口头补充。
- 客户端字段命名与本文一致，联调无字段错位。
- 金额字段全部为整数分，代码扫描无浮点金额。
- `caseSessionId`、`idempotencyKey`、`transactionId` 唯一约束生效，重复写入被拒。
- `pets.petId` 与 `adoptions.petId` 一对一，`adoptions` 不含展示字段，图鉴可正确联表读取。
- 配置可发布、灰度、回滚，客户端能按版本拉取。
- 清理任务可执行且不影响在线业务。
- 注销流程可级联删除个人数据，财务数据按策略保留。
