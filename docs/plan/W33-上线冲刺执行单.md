## 1. 执行原则

1. **评审 §8 的「明确不要做」直接生效**：不加新系统、不做 3D/骨骼/Live2D、不做多人、不做剧情树、提审前不重做大厅布局。
2. 只做能本地验证的改动；**部署 / 上传代码 / 提审 / 微信公众平台配置 / 云存储上传 / `deploy:cloud --apply` / force push 全部由人执行**，本单不含这些动作。
3. 每个 Sprint 结束必须有可复核证据：`tsc ×3` 零错误、`build success`、390×844 截图、CDP 断言。
4. 真实广告位 ID、真实协议/客服 URL、支付开闭、排行榜写入或下架属于产品/运营决策，代码侧只做「未配置即隐藏」的安全兜底。
