## 1. 通用约定

### 1.1 返回结构

```ts
interface CloudResponse<T> {
  code: number;
  msg: string;
  data: T | null;
  serverTime?: number;
}
```

- 成功：`code = 0`，`msg = 'ok'`。
- 失败：`code` 使用下表错误码，禁止用 HTTP 状态码替代业务码。
- 金额统一为整数分；时间统一为毫秒时间戳。

### 1.2 错误码

| code | msg | 含义 | 客户端处理 |
|---|---|---|---|
| 0 | ok | 成功 | 正常 |
| 1001 | SESSION_INVALID | 会话失效 | 重新登录 |
| 1002 | INVALID_PARAM | 参数错误 | 提示，不重试 |
| 1003 | RATE_LIMITED | 频控 | 提示稍后 |
| 1004 | DUPLICATE | 幂等重复 | 使用上次结果 |
| 2001 | INSUFFICIENT_RESOURCE | 资源不足 | 引导免费路径 |
| 2002 | INVALID_STATE | 状态非法 | 刷新状态 |
| 3001 | ORDER_MISMATCH | 订单不存在/金额不符 | 告警，人工核查 |
| 3002 | PAY_UNAVAILABLE | 支付不可用（W1–W4 固定） | 隐藏或禁用付费入口 |

### 1.3 身份与幂等

- `openid` 只从 `cloud.getWXContext()` 获取，任何请求体中的身份字段都不可信。
- 写操作必须携带幂等键；重复请求返回首次结果，不重复发奖/发货。
- 请求时间窗 ±5 分钟；超窗拒绝。

| 函数 | 幂等键 |
|---|---|
| `saveGame` | `openid + revision` |
| `syncCaseResult` | `openid + caseSessionId` |
| `assist` | `assist_pairs._id = targetId_helperId_yyyy-MM-dd` |
| `adEvent` | `openid:adSessionId` |
| `createOrder` | `openid + clientOrderId` |
| `payCallback` | `transactionId` |

## 2. 函数清单

### 2.1 `login`

| 项 | 内容 |
|---|---|
| 调用方 | `Boot` 启动 |
| 入参 | `{ scene?: string, version?: string, channel?: 'android' \| 'ios' \| 'dev' }` |
| 出参 | `{ token: string, isNewUser: boolean, serverTime: number, minVersion: string }` |
| 幂等 | 读操作；新用户创建需并发安全 |
| 频控 | 10 次/分/设备 |
| 错误 | 1002、1003 |

### 2.2 `getProfile`

| 项 | 内容 |
|---|---|
| 调用方 | `Login` 成功、`Lobby` 刷新 |
| 入参 | `{}` |
| 出参 | `{ user: UserSummary, hospital: HospitalState, resources: ResourceSummary, collection: CollectionSummary }` |
| 幂等 | 读操作 |
| 频控 | 30 次/分 |
| 错误 | 1001、1003 |

### 2.3 `saveGame`

| 项 | 内容 |
|---|---|
| 调用方 | 资源/医院状态变更后 |
| 入参 | `{ revision: number, snapshot: HospitalSnapshot }` |
| 出参 | `{ revision: number, serverTime: number }` |
| 幂等 | `openid + revision`；`revision <= current` 返回 1004 + 最新 revision |
| 频控 | 10 次/分 |
| 错误 | 1001、1002、1003、1004 |

### 2.4 `syncCaseResult`

| 项 | 内容 |
|---|---|
| 调用方 | `Result` 结算 |
| 入参 | `{ caseSessionId: string, caseId: string, diagnosis: DiagnosisInput, treatment: TreatmentInput, durationMs: number }` |
| 出参 | `{ result: CaseResult, rewards: RewardSummary, resources: ResourceSummary }` |
| 幂等 | `openid + caseSessionId`；已存在返回历史结果 |
| 频控 | 20 次/分 |
| 错误 | 1001、1002、1003、2002 |
| 硬规则 | 星级、治疗结果、奖励全部由服务端重算；客户端传入的奖励字段一律忽略 |

```ts
interface DiagnosisInput { type: 'auscultation' | 'xray' | 'lab'; stars: number; mistakes: number; durationMs: number }
interface TreatmentInput { result: 'success' | 'partial' | 'fail'; medicineUsed: string[]; bedUsed: boolean; healing: number }
```

### 2.5 `leaderboard`

| 项 | 内容 |
|---|---|
| 调用方 | `Lobby` 排行榜入口（W1 可只做 UI 占位） |
| 入参 | `{ type: 'reputation' \| 'collection' \| 'weekly', period?: string, limit?: number }` |
| 出参 | `{ entries: LeaderboardEntry[], self: LeaderboardEntry \| null }` |
| 幂等 | 读操作 |
| 频控 | 20 次/分 |
| 错误 | 1002、1003 |
| 硬规则 | `type` 白名单；`limit` 默认 20、最大 100；不返回 openid 明文，使用脱敏 ID |

```ts
interface LeaderboardEntry { rank: number; displayId: string; score: number; nickname?: string }
```

### 2.6 `assist`

| 项 | 内容 |
|---|---|
| 调用方 | 好友助力落地页 |
| 入参 | `{ friendOpenid: string, resourceType: 'medicine' \| 'bed' \| 'heart', nonce: string }` |
| 出参 | `{ granted: boolean, assisted: boolean, reason: 'ALREADY_ASSISTED' \| 'LIMIT' \| 'EXPIRED' \| null, dailyCount: number, resources: ResourceSummary \| null }` |
| 幂等 | `assist_pairs._id = targetId_helperId_yyyy-MM-dd`（主键冲突即已助力） |
| 频控 | helper 3 次/日；target 5 次/日（`assist_daily` 单文档 `inc` 计数） |
| 错误 | 1001、1002、1003、1005、2002 |
| 硬规则 | 目标方 openid 从上下文取，`friendOpenid` 由客户端传入且不得等于目标方；`nonce` 必填；超过目标方每日上限返回 `1005 TODAY_ASSIST_LIMIT`，客户端不得本地兜底发奖 |

### 2.7 `adEvent`

| 项 | 内容 |
|---|---|
| 调用方 | `Ad.showRewarded` 完成回调 |
| 入参 | `{ adSessionId: string, adUnitId: string, scene: string, isEnded: boolean }` |
| 出参 | `{ granted: boolean, reward: RewardSummary \| null, todayCount: number }` |
| 幂等 | `openid:adSessionId`（`ad_events.idempotencyKey` 唯一索引） |
| 频控 | 按广告位配置，激励视频全局 6–10 次/日 |
| 错误 | 1001、1002、1003、2001 |
| 硬规则 | `isEnded !== true` 不发奖；广告位与场景必须命中配置白名单 |

### 2.8 `createOrder`

| 项 | 内容 |
|---|---|
| 调用方 | `Pay.createOrder` |
| 入参 | `{ skuId: string, clientOrderId: string }` |
| 出参（正常） | `{ orderId: string, payParams: Record<string, unknown>, status: 'CREATED' }` |
| 出参（W1–W4） | `{ code: 3002, msg: 'PAY_UNAVAILABLE', data: null }` |
| 幂等 | `openid + clientOrderId`；已存在返回原订单 |
| 频控 | 5 次/分 |
| 错误 | 1001、1002、1003、3002 |
| 硬规则 | 价格只从服务端 SKU 读取；W1–W4 不调用统一下单，不返回支付参数 |

### 2.9 `payCallback`

| 项 | 内容 |
|---|---|
| 调用方 | 平台支付回调（W1–W4 不接真实回调） |
| 入参 | `{ platformPayload: Record<string, unknown> }` |
| 出参（W1–W4） | `{ code: 3002, msg: 'PAY_UNAVAILABLE', data: null }` |
| 幂等 | `transactionId` |
| 频控 | 平台侧控制 |
| 错误 | 3001、3002 |
| 硬规则 | W1–W4 不验真实报文、不发货；解冻后必须验签、校验金额、状态机迁移 |

### 2.10 `getConfig`

| 项 | 内容 |
|---|---|
| 调用方 | `Boot` 与 `Lobby` |
| 入参 | `{ version?: number, grayTags?: string[] }` |
| 出参 | `{ version: number, configs: Record<string, unknown>, forceUpdate: boolean, minVersion: string }` |
| 幂等 | 读操作 |
| 频控 | 60 次/分 |
| 错误 | 1002、1003 |
| 硬规则 | `configKey` 白名单；只返回 `active` 版本；灰度按标签与比例命中 |

## 3. 调用顺序

```text
Boot → login → getConfig → getProfile → Lobby
单局 → syncCaseResult → saveGame
广告 → Ad.showRewarded → adEvent
支付 → createOrder → (W1–W4: PAY_UNAVAILABLE) → payCallback（解冻后）
社交 → assist → getProfile
榜单 → leaderboard
```

## 4. 变更规则

1. 新增字段只能追加，不能改类型；客户端必须容忍未知字段。
2. 删除/重命名字段需双读一个版本，并更新 08/09/10 与本文。
3. W1–W4 不接受任何真实支付接口的接入申请，除非 00 第 16 节 F1 解冻。
4. 本文与 00 第 16 节冲突时，以 00 为准；本文内部冲突以本文第 1 节通用约定为准。
