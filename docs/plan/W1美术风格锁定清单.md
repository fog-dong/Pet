## 1. 锁定风格（不可协商）

| 维度 | 定义 |
|---|---|
| 核心词 | 温暖、治愈、手绘、绘本、柔和、可信 |
| 参考感受 | 儿童绘本 + 轻水彩 + 圆润卡通 |
| 情绪 | 忙碌但不焦虑；有困难但不残忍 |
| 视角 | 2D 正交 / 轻微俯视，竖屏构图 |

**风格关键词（英文，仅供沟通与提示词）：**

```text
2D hand-drawn mobile game art, warm healing storybook style, soft gouache texture,
rounded shapes, gentle morning light, muted pastel palette, cozy small-town clinic,
clean silhouettes, subtle paper grain, friendly rounded UI, no text
```

## 2. 禁止项（硬性，违反即打回）

1. 不出现写实手术、真实医疗器械品牌、针头刺入皮肤特写。
2. 不出现血液、伤口特写、骨折透视、动物痛苦挣扎。
3. 不直接描绘虐待、遗弃过程；遗弃只用“雨天纸箱”等含蓄表达。
4. 不使用真实宠物照片、真实病历、真实医生形象。
5. 不做恐怖、阴暗、高对比血腥色调；夜晚不用纯黑。
6. 图内不生成文字（文字由 UI 层排版）。
7. 不使用未授权 IP、明星形象、品牌 Logo、字体与音乐。

**“疼痛”表情只允许**：耷耳、眯眼、低头；不画伤口、不画泪水特写。

## 3. 色彩规范（冻结色板）

| 用途 | 色值 | 占比 | 使用场景 |
|---|---|---|---|
| 主背景 | `#F7EFE3` 奶油米 | 60% | 场景底色、页面背景 |
| 辅助 | `#A8C3A0` 鼠尾草绿 | 20% | 自然、成长、治愈反馈 |
| 强调 | `#D98E73` 陶土橙 | 10% | 主按钮、关键提示 |
| 辅助蓝 | `#A9C7D9` 雾蓝 | 5% | 轻医疗感元素 |
| 文字 | `#4A3F35` 深棕 | 5% | 正文与标题 |
| 危重态 | `#C97B6E` 低饱和暖红 | — | 仅状态标识，不做大面积 |

- 正文对比度 ≥ 4.5:1。
- 资源不足用暖色提示，不用红色警告；失败文案温和，不责备。

## 4. 角色 / 宠物 / UI 规范摘要

| 类别 | W1–W2 必须遵守 |
|---|---|
| 人物 | 2.5–3 头身、圆润、弱化性别特征；简洁医护围裙/针织衫，无真实医院标识 |
| 宠物 | 每品种保留 2–3 个识别特征（耳型、花纹、尾型）；统一站姿基线与画布 |
| UI | 720×1280 竖屏（D10 修正：与代码实际设计帧对齐，2026-10-30）；8px 栅格，间距 8/16/24；卡片圆角 16px、按钮 24px；点击区 ≥ 80×80px；描边统一 2px |
| 动效 | 200–300ms，缓入缓出，不强闪烁 |
