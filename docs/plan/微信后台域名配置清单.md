## 1. 先认清后端有两条通路（决定你要配哪些域名）

客户端 `EnvConfig.isCloudEnabled()` 的判定顺序是**先看 HTTP 后端，再看云开发**：

| 通路 | 打开方式 | 代码出口 | 需要合法域名吗 |
|---|---|---|---|
| **A. Axum HTTP 自建后端**（本版唯一启用，决策-6d） | 源码常量 `EnvConfig.API_BASE_URL = 'https://pet.jiangker.cn'`（W24-4 已落源码）；本地存储 `pet_api_base_v1` 只用于改指别的地址，写 `off` 可整体关闭 | `net/NetHttp.ts` 的 `wx.request` | **需要**，就是本单第 2 节 |
| **B. 微信云开发云函数**（本版**备用、不启用**） | 源码常量 `CLOUD_ENV` 仍是 `ENV_PLACEHOLDER`；要启用必须把真实环境 ID 写进源码（运行时 `pet_cloud_env_v1` 不会进提审包） | `net/NetCloud.ts` 的 `wx.cloud.callFunction` | **不需要**，`wx.cloud.*` 不走合法域名校验 |

两条通路只要任一可用，`Net.ready` 即成立；**同时打开时 A 优先**。本版 B 保持未配置，所以第 2 节两栏是**必做**——不做的话线上玩家每一次请求都会失败，登录、存档同步、排行榜、离线收益全部退回本地兜底。

**线上后端连通性实测（2026-11-03，本机 `curl`）**：`GET https://pet.jiangker.cn/health` → HTTP 200，耗时 0.75 s，body `{"status":"ok","api_version":"0.1.0","min_client_version":"0.0.0"}`。所以第 2 节不是「以后可能要配」，是**现在就差这一格**。

## 2. 必须添加的域名（公众平台 → 开发管理 → 开发设置 → 服务器域名）

入口：`https://mp.weixin.qq.com` → 用小程序管理员扫码 → 左侧「开发管理」→「开发设置」→「服务器域名」→ 修改。

| 类型 | 填写值 | 为什么需要 |
|---|---|---|
| **request 合法域名** | `https://pet.jiangker.cn` | 登录与全部业务请求走 `wx.request`（`NetHttp.ts:24`），支付下单同样走它（`Pay.ts:20`） |
| **downloadFile 合法域名** | `https://pet.jiangker.cn` | **当前代码并未从自有域名下载文件**（见第 3 节）。加上是为了后续把立绘/音效改成从 `pet.jiangker.cn` 直发时不必再改一次域名 |

**填写格式硬要求**（任一条不满足，保存时平台直接报错）：

- 必须 `https://` 开头，不能是 `http://`；
- 只能写协议 + 域名，**不能带路径、参数、端口号**（`https://pet.jiangker.cn/api` 与 `https://pet.jiangker.cn:8443` 都算填错）；
- 域名必须**已完成 ICP 备案**（微信侧会校验备案主体，未备案域名无法保存）；
- 修改服务器域名需要管理员扫码确认，且平台对每月修改次数有限制——**一次把两栏填对，别反复改**。

## 3. 本次**不需要**配置的项（逐条给依据，避免多做动作）

| 类型 | 结论 | 依据 |
|---|---|---|
| **connectSocket（wss://）合法域名** | **不需要** | 全项目 `assets/scripts/**/*.ts` 内没有任何 `wx.connectSocket` 调用。`game.json` 里的 `connectSocket: 5000` 只是超时声明，不代表使用 |
| **uploadFile 合法域名** | **不需要** | 客户端无 `wx.uploadFile`；资源上传走云开发控制台/服务端，不由小游戏端发起 |
| **downloadFile（云存储资源）** | **不需要额外域名** | `CloudResCache.ts:27` 用 `wx.cloud.downloadFile({ fileID })`，云存储下载按 `fileID` 寻址，不受合法域名白名单约束 |
| **业务域名 / 购物消息域名** | 不涉及 | 本项目无 web-view（小游戏本身不支持），也无电商类目 |

## 4. 备案与证书前置（域名能保存的硬条件）

1. **ICP 备案**：`pet.jiangker.cn` 所属主域名 `jiangker.cn` 必须已在工信部备案成功，且备案主体与小程序主体一致或可解释。新增二级域名通常沿用主域名备案，但**接入商必须包含当前服务器所在机房**（服务器在阿里云/腾讯云，就在那边做「新增接入」）。
2. **HTTPS 证书**：证书链完整、未过期、覆盖 `pet.jiangker.cn`。微信不接受自签证书，也不接受只签 `*.jiangker.cn` 却用于裸域名的组合。
3. **TLS 版本**：微信要求 TLS 1.2 及以上。Nginx 侧确认 `ssl_protocols TLSv1.2 TLSv1.3;`。
4. **80/443 可达**：备案核查与证书续期常走 80 端口，别只开 443。

## 5. 配置完成后的自检（按顺序，每步看真实返回）

```bash
# ① 证书链与 TLS 版本（在你本机跑，不碰服务器密钥）
curl -v --tlsv1.2 https://pet.jiangker.cn/health

# ② 期望：HTTP/2 200，且 body 形如
#    {"status":"ok","api_version":"...","min_client_version":"..."}
```

3. 微信开发者工具 →「详情 → 本地设置」**取消勾选**「不校验合法域名」，重新编译。
   勾着这项时域名配错也不会报错，**这是提审前最容易漏的坑**。
4. 取消勾选后若控制台出现 `request 合法域名校验出错`，说明第 2 节填写值与实际请求地址不一致（常见于多了尾斜杠或端口）。
5. 真机预览：走一遍「大厅 → 接诊 → 结算 → 排行榜」，四步都有服务端响应即通路健康。
6. **联调换地址**才需要运行时覆盖位（不改源码、不提交）：

```js
wx.setStorageSync('pet_api_base_v1', 'https://pet.jiangker.cn')   // 指到别处（例如测试机）
wx.setStorageSync('pet_api_base_v1', 'off')                        // 关闭 HTTP 通路，回落云开发/本地
```

回滚口径已在 W24-4 改变：源码里现在有默认地址，**`wx.removeStorageSync('pet_api_base_v1')` 不再等于关闭**，只会回到源码默认值；要临时停写请写 `off`（自动化用例 `verify-habitat` / `verify-life` / `verify:mainchain` 就是靠它保持自闭环、不打线上）。
