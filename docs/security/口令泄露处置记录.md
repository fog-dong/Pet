## 6. 为什么先吊销、后（可选）清历史

- 吊销使旧值立即失效，成本 ≈ 5 分钟，无需协调任何人。
- 清历史要改写全部 commit hash + force push，所有 clone 必须重来；风险与收益不对称，应在止血之后按需决定。
- 顺序颠倒（先 force push 不吊销）等于把无效动作当成安全措施，旧凭据仍然可用。
