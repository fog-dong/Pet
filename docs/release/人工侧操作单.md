## A. 占位跑通版（现在就能做，不要求真实资质）

| # | 事项 | 怎么做 | 现在的预期行为 | 代码/配置落点 |
|---|---|---|---|---|
| A1 | AppID 继续用游客占位 | 开发者工具导入 `build/wechatgame-release`，AppID 选「测试号/游客」即可，只做模拟器运行 | `touristappid` **不能生成真机预览二维码**，这是平台限制，不是工程缺陷 | `build-templates/wechatgame/project.config.json:15` |
| A2 | 开通云开发拿环境 ID | 开发者工具「云开发」→ 开通（个人账号可选按量计费）→ 复制环境 ID | 没填之前 `isCloudEnabled()` 为 false，云端功能全部走本地兜底，游戏仍可完整玩单局；填了并重新构建后 `Net.ready` 才可能为 true | `assets/scripts/config/EnvConfig.ts:5`（`CLOUD_ENV`），判定见 `:16-17` |
| A3 | 上传 11 个云函数 | **先**在仓库根执行 `npm run build:cloud`（生成带 `// GENERATED` 头的 `index.js`），再在开发者工具左侧 `cloudfunctions` 目录上**右键 →「上传并部署：云端安装依赖」**，逐个执行；顺序：`login` → `getConfig` → `saveGame` → `syncCaseResult` → `leaderboard` → `assist` → `adEvent` → `getProfile` → `trackEvent` → 其余 | 未部署时所有云端调用返回错误码，客户端按既有语义降级（不崩、不阻塞）；`login` 缺 `SESSION_SECRET` 会抛 `SESSION_SECRET_MISSING`，属预期，见 A7 | 部署清单《W7-云函数部署操作单》；`cloudfunctionRoot` 已在模板里指向 `../../cloudfunctions/` |
| A4 | 本地调试跳过域名校验 | 「详情 → 本地设置」勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」 | 只对当前项目的**模拟器**生效；真机预览需在手机上点「打开调试」。W10 不处理域名白名单，正式域名在提审前由运营在公众平台配置 | 无代码改动（纯工具设置） |
| A5 | 广告保持占位 ID | 什么都不用做，7 个广告位仍为 `AD_UNIT_PLACEHOLDER` | 点广告按钮 → `Ad` 直接返回 `AD_UNAVAILABLE`，**不发奖、不扣当日次数、不调 `wx.createRewardedVideoAd`**，埋点 `ad_unconfigured`；这是预期行为，不要填假 ID 让它「看起来能跑」 | `assets/scripts/config/AdConfig.ts`；保护链路 `net/Ad.ts:38`、`net/AdGateway.ts:51-55` |
| A6 | 协议与客服用占位 URL | 什么都不用做，现为 `https://example.com/*` | 自检函数把 `example.com` 判为**未配置**：关于面板直接显示兜底文案，不会拿占位 URL 去调客服接口；弹窗正文照常展示 `points` 摘要 | `assets/scripts/config/LegalConfig.ts:91-102` |
| A7 | 云函数环境变量 | 云开发控制台给 `login`（及依赖 token 的函数）配置 `SESSION_SECRET`，值用随机强密钥 | 缺失时 `login` 直接抛错，客户端 `boot_login_failed` 埋点，游戏仍进大厅走本地模式 | 控制台配置，**不写进仓库、不提交** |
| A8 | 幂等与频控回归 | 在云开发控制台「云函数 → 测试」里用同一 `adSessionId` / 同一 `targetId_helperId_date` 重复调用 | 重复调用回放首次结果，不重复记账；本地已用 `npm run verify:idempotency`（mock db）跑通 3 用例 | `scripts/verify-idempotency.js` |

预览（生成二维码）在占位版**不做**：`touristappid` 不支持，必须等 B1。

## C. 两栏之间的关系

1. A 栏全部完成后，游戏在**模拟器**里可以玩通全部本地内容：单局、图鉴、病例、本地存档；云端功能要到 A2/A3/A4 完成后才真正生效。
2. B 栏任一项未完成都不影响 A 栏继续跑；但 B1–B4 是提审硬门槛，B5 是定级依据（很多 P1/P2 警告只有在真机才能关闭）。
3. 所有占位值的字段级清单在《占位替换清单.md》，本单不重复字段名与占位值，只写动作与验收。
