## 6. 与计划的偏差（须记录）

1. **MCP 工具能力与预期不符**：`sanchong-mcp-cocos@1.0.107` 共 233 个工具，**没有 `create_scene`、也没有 `build_wechatgame`**（`cc_project_ops` 仅 `get_status` / `get_project_path` / `save_scene`）。因此场景不是由 MCP 直接"创建"，而是：复制 Creator 自带模板 `default_file_content/scene-2d` → 由编辑器导入生成 `.meta` → 再用 MCP 的节点/组件/属性工具搭建内容。构建走官方 CLI。
2. **MCP 的变更校验串不可信**：`create_label`、`create_button_with_label`、`cc_component_typed_ops add`、`assign_reference` 均返回"变更确认失败"，但读回（`get_list` / `get_properties` / 直接解析 `.scene`）证明全部生效。结论：一律以读回为准。
3. **CLI 构建退出码恒为 36**：无论是否有编辑器实例占用 3000 端口、日志中 `error` 行数为 0 且出现 `build success in … ms!`、产物时间戳刷新——退出码 36 是 Creator CLI 在 Windows 上的进程退出行为，**不代表构建失败**。为消除 `EADDRINUSE :::3000`，构建期间已临时移出 `extensions/sanchong-mcp-cocos`（该目录已被 git 忽略）。
4. **`--build "appId=touristappid"` 参数不生效**：产物仍写入 Creator 占位 appid `wx6ac3f5090a6b99c5`。改用 `build-templates/wechatgame/project.config.json` 覆盖，已实测生效。
