## 一、适龄提示

| 项 | 事实 |
|---|---|
| 设置位置 | 微信公众平台 → 设置 → 基础设置 → 基本信息 → **适龄提示**，提交后由平台审核 |
| 推荐档位 | **8+**：参考标准为卡通手绘、少量简单合作、**无陌生人社交**；本作为宠物医院经营模拟，符合该描述 |
| 展示方式 | 平台审核通过后，在启动页《健康游戏忠告》**右侧统一展示**；**游戏内不要重复画一个** |
| 截图要求 | 截图必须**同时出现**「健康游戏忠告」「适龄提示」「游戏名称」三项 |
| 代码现状 | `core/Boot.ts` 启动页底部绘制 `AGE_RATING_TEXT`（「适龄提示：8+」，底距 88px）与 `HEALTH_GAME_NOTICE_TEXT`（底距 48px）；`ui/AboutPanel.ts` 也展示同一常量；**启动页未单独绘制游戏名称**，名称是否由微信启动页标题呈现需真机截图确认 |
| 风险 | 平台统一展示后，游戏内再画「适龄提示：8+」会**重复**；是否移除 Boot 行需按平台实际展示确认（本轮不改代码） |

**当前状态：未实现（平台适龄提示未设置、合规截图未产出；游戏内忠告+适龄已绘制，游戏名需真机确认）。**

## 二、隐私与协议

| 项 | 事实 |
|---|---|
| 硬要求 | 隐私政策、用户协议必须是**真实可访问的 H5 页面**，不能是空白模板；这是高频驳回点 |
| 当前 URL | `config/LegalConfig.ts` → `LEGAL_DOCS`：隐私 `https://example.com/privacy`、用户协议 `https://example.com/agreement`、未成年人保护说明 `https://example.com/minors`，全部为**占位** |
| 自检 | `legalUrlsReady()` 把 `example.com` 判为未配置；`core/Boot.ts` 隐私门后记 `boot_legal_urls_placeholder`，Debug 构建额外 warn，不阻塞本地流程 |
| privacyAccepted 当前值 | 不是常量，存在本地 `sys.localStorage` 键 `pet_privacy_v1`：`{ privacyAccepted, acceptedVersion, guestMode }`；新装默认 `privacyAccepted=false`、`acceptedVersion=''`、`guestMode=false`；`accepted()` 只有在 `acceptedVersion === LEGAL_VERSION` 时才为真 |
| LEGAL_VERSION 当前值 | `'1.0.0'`（`config/LegalConfig.ts`） |
| 版本变更行为 | 协议文案或采集范围变更后必须递增 `LEGAL_VERSION`；已同意玩家会因版本不匹配**重新弹隐私窗** |
| 弹窗内正文 | 不依赖 H5，`LEGAL_DOCS[].points` 常量直接展示；但平台审核仍要求可访问的 H5 |

**当前状态：占位待换（3 个 H5 与 `LEGAL_VERSION` 均未替换；H5 未上线前不得提审）。**

## 三、健康忠告与医疗免责

| 项 | 事实 |
|---|---|
| 健康游戏忠告（48 字） | 「抵制不良游戏，拒绝盗版游戏。注意自我保护，谨防受骗上当。适度游戏益脑，沉迷游戏伤身。合理安排时间，享受健康生活。」（含标点 56 字符，标准口径按 48 字计） |
| 医疗免责声明 | 「本游戏为虚构的宠物医院模拟玩法，所有诊断、用药与治疗均为游戏设定，不构成任何医疗或兽医建议。」 |
| 展示位置 | 启动页 `BootSplashLegal` 挂在 Canvas 下并走安全区：忠告底距 48px、适龄底距 88px；病例页左下固定展示免责；关于面板常驻展示 |
| 显示时长 | 启动页合规两行必须常驻 ≥ `SPLASH_MIN_MS`（**3000ms**）才允许进大厅；读协议耗时超过 3 秒时只补足缺口，不叠加等待 |

**当前状态：已就绪（文案与展示代码已落地；平台适龄设置与合规截图另见第一组）。**

## 四、客服与反馈

| 项 | 事实 |
|---|---|
| 代码入口 | `ui/AboutPanel.ts`「联系客服」→ `net/Support.ts` → `wx.openCustomerServiceChat`（业务层唯一出口） |
| 当前配置 | `CUSTOMER_SERVICE.url = https://example.com/customer-service`（占位）；`scene = '宠物医院小游戏-关于面板'`；`fallbackText = '客服系统配置中，可通过公众号留言反馈。'` |
| 当前行为 | `customerServiceReady()` 为 false → 不拿占位 URL 调接口，直接回显兜底文案；打开失败/基础库不支持同样回显，不崩溃、不静默 |
| 提审前要求 | 二选一：① 公众平台开通微信客服并填入官方下发 URL；② 换成真实可访问的反馈 URL（需同步改 `Support.ts` 的打开方式，不能只改常量） |
| 后台要求 | 小游戏后台配置客服入口，明确响应时效与投诉处理流程 |

**当前状态：占位待换（兜底文案可用，但提审前必须接真实客服或反馈 URL）。**
