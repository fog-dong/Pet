## 2. 性能目标

| 指标 | 目标 | 底线 | 测量条件 |
|---|---|---|---|
| 主包体积 | ≤4MB | ≤4MB（硬上限） | 构建产物 |
| 分包总体积 | ≤30MB | ≤30MB（硬上限） | 构建产物 |
| 首屏时间 | <3 秒 | <5 秒 | 中端 Android、4G、冷启动 |
| 页面切换 | <300ms | <500ms | 中端机 |
| 帧率 | 中高端 60 FPS | 低端 30 FPS | 真机 |
| 内存峰值 | ≤200MB | ≤250MB | 低端 Android |
| Draw Call | <80 | <120 | 大厅/单局 |
| 纹理内存 | <120MB | <160MB | 单场景 |
| 包内请求数 | 首屏 ≤5 个 | ≤8 个 | 冷启动 |
| 崩溃率 | <0.5% | <1% | 灰度 |

> 平台包体限制、基础库能力以官方文档为准；上表为规划目标，需真机实测。包体与内存口径已按 00 第 16 节 F3 冻结：主包 ≤4MB、总分包 ≤30MB、内存 ≤200MB、低端机 ≤250MB。

## 3. 优化手段

| 方向 | 措施 |
|---|---|
| 包体 | 图集合并、WebP/压缩纹理、音频压缩、删除未用资源、配置外置 |
| 首屏 | 延迟初始化、并行加载、首屏只加载必要图集、登录与配置并行 |
| 渲染 | 合批、减少 Mask/Blend、控制同屏节点数、避免全屏重绘 |
| 内存 | 分包按页加载、引用计数释放、对象池、避免大图常驻 |
| 网络 | 请求合并、缓存、弱网重试（见 08）、避免首屏串行请求 |
| 动画 | 骨骼动画复用、限制同屏 Spine 数量、低端机降级 |
| 音频 | 按场景加载、单声道、压缩格式、切后台暂停 |

## 5. 发布前检查清单

### 5.1 工程与包体

- [ ] 主包 ≤4MB、总分包 ≤30MB，构建无警告
- [ ] 无调试代码、测试开关、假数据、console 日志
- [ ] 资源无重复、无未引用大图
- [ ] 版本号、渠道号、环境配置正确
- [ ] 灰度与回滚方案已演练

### 5.2 功能与数据

- [ ] 单局闭环、领养、图鉴、分享、助力可走通
- [ ] 支付沙箱闭环，重复回调不重复发货
- [ ] 广告奖励可对账，失败有兜底
- [ ] 存档双写、断网恢复、切后台恢复通过
- [ ] 埋点事件齐全，看板可查
- [ ] 客服入口与 FAQ 可用

### 5.3 合规

- [ ] 类目与资质齐全（以平台要求为准）
- [ ] 隐私政策、用户协议、儿童/未成年人条款
- [ ] 实名与防沉迷按平台要求接入
- [ ] 无医疗诊断/治疗承诺，无真实药品与器械暗示
- [ ] 无血腥、虐待动物、真实病历内容
- [ ] 无强制分享、无诱导群分享（见 06）
- [ ] 广告无诱导点击、无虚假关闭按钮（见 11）
- [ ] 支付无站外引导，iOS 按政策降级（见 09/12）
- [ ] 内容无侵权素材、字体与音乐授权齐全
- [ ] 客服渠道、响应时效、退款流程明确

- 支付与广告可对账，异常有告警与处理人。
- 合规十类均有证据文件，缺失项在上线前清零。
- 灰度与回滚可在 30 分钟内完成。
