## 0. 结论先行

1. **现在的「空白 Demo 感」不是配色问题，是渲染方式问题**：全项目 UI 由 `addRect` 画纯色矩形，每块矩形一个 `Graphics`（一次 draw call），没有九宫格、没有阴影、没有按下反馈、没有场景分层。改动要从「渲染件」入手，而不是换色号。
2. **主包只剩约 750KB**（4MB 上限，当前 3.42MB，其中引擎 2.94MB）。所有新增 UI 贴图、字体**必须进分包**，否则第一阶段没做完就会顶破主包。这是本方案的第一硬约束。
3. **9 宫格底板用脚本过程化生成，不用 AI 生图**：AI 出不了边角严格对齐的九宫格，按钮拉伸必糊。过程化生成可精确控制圆角/描边/渐变，且一张图可染多种色。AI 只负责有机装饰（前台桌、绿植、软垫、logo）。

## 2. 全局视觉规范（新增，落地为代码常量）

### 2.1 新增 `ui/Tokens.ts`（唯一视觉口径）

| Token | 值 | 来源 |
|---|---|---|
| `bg.cream` | `#F7EFE3` | 16 §4 主背景 |
| `bg.floor` | `#EFE2D2`（米白地板，比墙深一档） | 派生 |
| `accent.terracotta` | `#D98E73` | 16 §4 强调（主按钮） |
| `brand.sage` | `#A8C3A0` | 16 §4 辅助（次按钮/成功） |
| `info.mist` | `#A9C7D9` | 16 §4 医疗感（信息/加速） |
| `text.ink` | `#4A3F35` | 16 §4 文字 |
| `text.sub` | `#7B6B5E` | 派生（原 `#7A6E64` 微调） |
| `panel.paper` | `#FFFCF5` | 卡片纸面 |
| `shadow.soft` | `#000000` @ 12% | 投影 |

- 圆角：卡片 16、按钮 24、Toast 999（胶囊）——16 §6 原值。
- 间距进制 8 / 16 / 24；卡片内边距 24，卡片间距 16。
- 动效：200–300ms，`ease-out` 进场、`backOut` 回弹；不做闪烁。
- `PALETTE` 保留导出名（避免改 40+ 处调用），内部改为引用 Tokens；**`PALETTE.primary` 由 `#EE945C` 改为 `#D98E73`，属色值纠偏，见 §2.7**。

### 2.2 层级模型（每页统一五层）

```
L0 环境底板  墙面 + 地面 + 踢脚线（Graphics 色块，零贴图）
L1 环境装饰  绿植 / 前台桌 / 挂架 / 软垫（Sprite，来自 ui 分包）
L2 内容卡片  纸面卡片、棋盘、选项行（九宫格 Sprite）
L3 交互件    按钮、Toast、浮字、星星
L4 遮罩层    弹窗 overlay + 面板
```

所有页面由 `Backdrop.mount(root, variant)` 一次搭好 L0/L1，页面自己只写 L2/L3。

### 2.3 轻投影规范

卡片统一在下方叠一层同尺寸圆角矩形（`#000` 12%，y 偏移 6px，模糊用两层叠加模拟），**不使用实时阴影**（小程序无内置模糊，成本高）。按钮同理（偏移 4px）。low 档只保留一层 8%。

### 2.4 九宫格

九宫格贴图放 `ui` 分包，运行时 `spriteFrame.insetLeft/Right/Top/Bottom = 24`（代码里显式设，不依赖 meta 导入参数，避免不同机器导入结果不一致）。

### 2.5 字体（**待裁决**）

| 方案 | 做法 | 体积 | 影响 |
|---|---|---|---|
| A（推荐） | 圆体子集包进 `ui` 分包，`Label.font` 运行时替换；加载失败回落系统字 | 子集 ≤180KB | 需 16 §6「字体」行改口径；需确认授权 |
| B | 保持系统字体，只做字重/描边/斜体层级 | 0 | 不改冻结文档，质感提升有限 |

候选字体（均免费商用，需在「关于」页与提审材料注明来源）：站酷快乐体、阿里妈妈数黑体、沐瑶软笔。

**只收实际用到的字**（当前全项目约 500–700 个汉字），由脚本扫描 `assets/**/*.ts` 字符串 + 固定法务文案生成子集。不做全量 GB2312。

### 2.6 合规文案不动

`Medical` 免责句、适龄提示、隐私协议正文/按钮、健康游戏忠告：**文字与位置一律不改**，只换外框（纸卡）与字色。文案改造范围见 §6。

### 2.7 需要回写 16 号文的偏差（共 3 处）

1. 字体：由「思源黑体/系统字体」→ 圆体（方案 A 通过时）。
2. `PALETTE.primary` 当前 `#EE945C` 与 16 §4 的 `#D98E73` 不一致，按 16 收敛。
3. 新增「环境底板 / 装饰层」资产类别（16 §7 未列），需补一行交付规格。

## 7. 动效规格（统一写进 Tokens）

| 动效 | 时长 | 缓动 | 触发 |
|---|---|---|---|
| 按钮按下 | 0.12s → 0.18s 回弹 | `backOut` | TOUCH_START / END |
| 卡片进场 | 0.24s，y +24 → 0，alpha 0→1 | `easeOut` | 页面 start（逐张延 40ms） |
| Toast | 进 0.2s / 停 2.2s / 出 0.2s | `easeOut` | 调用 |
| 星星 | 每颗 0.26s，间隔 0.14s，1→1.2→1 | `backOut` | 结算页 |
| 飘字 | 0.9s，上浮 120px + 渐隐 | `easeOut` | 加币/加心 |
| 转场 | 出 0.18s / 入 0.25s | 线性 alpha | 场景切换 |
| 拖拽高亮 | 0.15s 1→1.04 | `easeOut` | 拖拽开始 |

`Quality.low`：关闭卡片进场、飘字、星星回弹、进度条光泽；Toast 保留（信息可达性）。
