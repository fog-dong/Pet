# 公众平台注册信息填写建议

> 场景：微信公众平台注册小游戏，填写「名称 / 简称 / 头像 / 介绍」。
> 约束：平台上的名称必须与 `assets/scripts/config/LegalConfig.ts` 的 `GAME_NAME` **逐字一致**；改名就要同步常量、重建、重出启动页截图。

## 一、名称

| 项 | 内容 |
|---|---|
| 填写 | `萌宠救助日记` |
| 字符数 | 12 / 30（一个中文字算 2 字符） |
| 平台反馈 | “你的名字可以使用”（已通过校验） |

命名逻辑：保留“萌宠 + 日记”的轻松治愈感，把触发医疗资质审核的“诊所”换成“救助”，既贴合玩法（救助 → 护理 → 领养），也不再指向医疗服务。**不要再改回含“医院 / 诊所 / 医疗 / 宠物医生”的名称**，会再次触发行业资质校验。

## 二、简称

规则：4–10 字符（即 2–5 个中文字），且只能从全名中**按顺序连续**选取。

| 候选 | 平台字符数 | 是否合规 | 建议 |
|---|---|---|---|
| `萌宠救助` | 8 | ✅ 连续 | **首选**，品牌指向清晰，任务栏显示完整 |
| `救助日记` | 8 | ✅ 连续 | 备选，弱化“萌宠” |
| `萌宠` | 4 | ✅ 连续 | 仅当上面两个被占用时用；过泛，易与其他产品混淆 |
| `萌宠日记` | 8 | ❌ 不连续（跳过“救助”） | 不可用 |

简称会出现在微信“任务栏”等窄位，**不要超过 4 个中文字**；选定后与头像一起构成最小识别单元，后续买量素材沿用同一组合。

## 三、头像

平台要求：PNG / JPG / JPEG / GIF，≤2 MB，建议 144×144；不得含政治敏感或色情内容；预览会同时按方形和圆形裁切。

专业做法：

1. **主体**：一个正面、圆润的猫/狗角色半身像，配一个小房子或爱心轮廓，直接复用游戏内主角配色（当前启动页/大厅同一套暖色系）。
2. **构图**：主体占画面 70%，居中，四周留白 ≥12 px；圆形裁切后耳朵和下巴不能被切掉。
3. **背景**：纯色或极浅渐变（暖米色 / 浅青），不要场景图，保证 48×48 缩略时仍可辨认。
4. **禁止元素**：红十字、白大褂、听诊器、注射器、医院/诊所招牌、“宠物医院”字样——与改名原因同源，避免被判定为医疗类服务。
5. **不加文字**：144×144 下任何中文字都会糊；名称由平台在图标旁展示。
6. **格式**：导出 144×144 PNG（可同时留 512×512 源文件），控制在 200 KB 内，避免上传被压缩。

> 现有素材可直接从启动页角色立绘裁切；若需要新画，建议按上述规范生成后人工确认圆裁效果再上传。

## 四、介绍（≤120 字符）

推荐文案（109 字符，留 11 字符余量）：

```
《萌宠救助日记》是一款轻松治愈的宠物救助经营小游戏。你经营一家流浪动物救助站，接待受伤的小动物，通过观察、检查与护理帮助它们康复，再为它们寻找温暖的新家。游戏含病例挑战、图鉴收集与领养记录，操作简单，适合碎片时间游玩。
```

备选短版（91 字符），适合更强调“轻量”：

```
《萌宠救助日记》是一款轻松治愈的宠物救助经营小游戏。你经营一家流浪动物救助站，照顾受伤的小动物，帮它们康复并寻找新家。游戏含病例挑战、图鉴收集与领养记录，操作简单，适合碎片时间游玩。
```

写作口径：

- 用「救助 / 护理 / 康复 / 领养」，不用「诊疗 / 治疗疾病 / 医疗诊断」，避免被理解为提供医疗服务；
- 说明玩法闭环（接待 → 护理 → 康复 → 领养）与轻量节奏，便于审核判断内容与名称一致；
- 不写“最 / 第一 / 治愈系天花板”等绝对化或夸大用语；
- 不写外部联系方式、二维码、诱导分享；
- 不承诺真实领养服务，避免与实际功能不符。

## 五、连带要同步的项

| 项 | 值 / 动作 |
|---|---|
| 适龄提示 | 平台后台设为 `8+`，与 `LegalConfig.AGE_RATING` 一致 |
| 隐私协议 / 用户协议 | 替换 `LegalConfig` 中的占位 URL 后重新构建 |
| 服务类目 | 按小游戏要求选择游戏类目，准备版号 / 备案材料（以平台当前要求为准） |
| 启动页截图 | 名称改动后必须重出 8 张提审截图（见 `W15-提审截图预演清单.md`） |
| 代码常量 | 名称最终以平台审核结果为准，确定后只改 `GAME_NAME` 一处并重建 |

## 六、提交前自查

- [ ] 名称与 `GAME_NAME` 完全一致，且不含医疗词汇
- [ ] 简称连续取自全名、4–10 字符
- [ ] 头像 144×144、圆裁不切主体、无医疗元素与文字
- [ ] 介绍 ≤120 字符、无绝对化用语、玩法描述与实机一致
- [ ] 适龄等级后台与代码同为 8+
- [ ] 协议 URL 已替换，不是 `example.com` 占位
