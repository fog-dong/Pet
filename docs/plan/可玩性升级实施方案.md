## 0. 一句话结论

大厅从「木桌 + 悬浮按钮」改成**下重上轻的 2.5D 场景**（底部是诊所地板，领养宠物以真正看得清的脸趴在垫子上；顶部只剩资源与两个主入口）；小屋从「点卡片 → 弹 560×490 四键菜单 → 再点一个按钮」**改成面板内直接互动**（点宠物＝抚摸并 Q 弹，点属性图标＝喂食/洗澡）。其余（抽卡、诊断小游戏、装修、任务、看板宠台词）全部排进 P1/P2，本方案不实现。

有 **4 处做不到的字面指标**（§6）；5 个待拍板问题已于 2026-11-03 全部确认，结论见 §9。

### 1.4 音效现状（模块二第 3 条的硬约束）

`config/AudioConfig.ts` 注册 **9 条 cue**（`catCry dogCry rabbitCry birdCry treatOk recoverTick feed bath pet`），但 `AUDIO_TABLE` 的 `cloudKey` / `bundlePath` **全为空串** → 实际上传 **0/9**。当前只有 `feed / bath / pet` 有合成 beep 兜底（660/110、520/140、780/90 Hz），其余走 `Sfx.play()` 时静默。
→ 「所有交互必须接短促清脆的 ASMR 音效」这条，**代码侧能做的只有：给每个交互补 cue 调用 + 扩充合成兜底参数（不同音色/长短/包络）**；真 ASMR 素材是 `提审前人工操作单` 里那条「9 条音效上传」的人工项，不由本方案解决。qa-3 也是同一条：「实机只有位移与静态立绘，没有任何叫声」。

## 2. P0-1　大厅视觉与布局重塑

### 2.1 目标形态（一屏 720×1280，FIXED_WIDTH，横向只允许 ±360）

```
┌ 顶部（安全区内）────────────────────────┐
│  [🪙 1,240]  [❤️ 38]        ← 仅 2 个胶囊，top 走 safeAreaTop
│            萌宠救助日记（标题 40→34，让位）
├ 中层（背景叙事）────────────────────────┤
│   墙面 + 绿植 + 医生（size 320→300，缩一档）
│   前台桌 700（宽不变）
├ 底部（主角区，本次新增）────────────────┤
│  地板散步带：已领养宠物 最多 3 只，size 240
│   🐍垫子(ui_cushion)  🐍垫子      🐍垫子
│  主按钮（fitWidth(560)）＋ 一行入口（小屋/图鉴/…）
└──────────────────────────────────────┘
```

要点：
1. **主角给宠物，不给医生**。医生从 320–620 收敛到 300–480，把「占屏宽 1/3」的视觉预算让给宠物。
2. **240px = 屏宽 1/3**，一只正好、两只会打架（2×240 = 480，留白不足）。所以散步带按**可见 3 只 + 超量左右滑**：单只 240，间距 250，第 1 只居中偏左，其余按 `PetBehavior` 已有的档位各自呼吸/摇尾，眼睛是立绘自带（`art/pets/` 的正面构图）。
3. 立绘脚下垫一块 `ui_cushion`（`ui/Backdrop.ts` 已注册该帧，`DECOR_ASPECT 1.714`、占位色 `#F3E3C8`），**不需要新美术**；缺图时按现有 `addDecor` 的 roundRect 占位色渲染，不报错。
4. 点击散步带任一只 → 打开宠物小屋面板并滚动定位到该只（复用 `HabitatPanel` 的 ScrollView，符合 G3「不新建 Habitat 场景」）。无领养宠物时该带显示文案「救回第一只小家伙后，它会在这里等你」（V1.1 R1 原文）。

⚠️ 图鉴双列会同时挂载 2× 数量的 `PetVisual`，而每只都要 `Res.loadBundle('art')` 里的帧——audit-8 已经指出「20 个并发分包加载」缺虚拟化。放大 + 双列会把这个隐患放大，所以**双列必须与虚拟化（只渲染可见 ±4 行）同批做**，否则不做双列。

## 4. 动效规格（模块二第 2 条 + 无美术前提）

### 4.1 Personality：**Playful**（拍板-2 已确认）

150–300ms、`ease-out-back`（cc 内置 `backOut`）、overshoot 10–20%。理由是本项目调性为治愈系 + 捏捏乐式的 Q 弹，Playful 与现有 `backOut` 回弹和 `PetBehavior` 的呼吸档位天然连续。项目级动效身份三件套：**签名缓动 `backOut`（回弹/强调）+ `quadOut`（位移/入场）**、**Duration palette 见 §4.2**、**入场范式 = 自下 14px 位移 + opacity，stagger 0.06**（沿用 `MotionKit.RISE` / `STAGGER`，不新发明）。

### 4.2 Duration palette（`Tokens.DURATION` 扩表，不另起一套）

| 名称 | 秒 | 缓动（cc 名字） | 用途 | 现状 |
|---|---|---|---|---|
| press | 0.10 | `quadOut` | 按下 | 0.12，微调 |
| release | 0.18 | `backOut` | 回弹 | 已存在 |
| **squashIn** | **0.09** | `quadOut` | 挤压到底 | 新增 |
| **squashOut** | **0.26** | `backOut(overshoot≈1.7)` | 回弹过冲 | 新增 |
| **toss** | **0.45** | x:`linear` / y:`quadOut→quadIn` | 道具抛物线 | 新增 |
| **chew** | **0.12 × 2** | `sineInOut` | 咀嚼脉冲 | 新增 |
| **particle** | **0.75** | `quadOut` + `fadeOut` | 爱心/泡泡 | 新增（`float` 0.9 可参考） |
| card | 0.24 | `quadOut` | 卡片/行入场 | 已存在 |
| bandIn | 0.30 | `backOut` | 大厅散步带入场 | 新增（`MotionKit.RISE 14`，stagger 0.06，3 只总预算 0.28s < 500ms ✅） |

规则：入场比出场长 30–50%；空间位移**禁止 linear**（抛物线的 x 分量除外，它与 y 合成后不是 linear 运动）；状态变化**禁止只动 opacity**。

### 4.3 逐元素规格（三层动效）

**① 抚摸 Q 弹（主角，三层齐全）**
- Primary：`scale` 打到 `(1.14, 0.86)`（squashIn 0.09）→ 回弹 `(0.96, 1.06)` → 归 `(1,1)`（squashOut 0.26）。跟随手指方向：横向分量随触点在立绘左/右侧变号。
- Secondary：爱心粒子 6 颗从触点上方 20px 出生，x 微散 ±40，y 上升 120，带 ±8° 摆动，0.75s 内 `quadOut` + 尾段淡出；`FloatText`「+10 心情」用 `COLORS.clay`。
- Ambient：立绘脚下阴影（`withShadow` 已支持 `${name}Shadow`）随 squash 同步 `scaleX 1.08 → 1`。
- 已存在但被替代的：`playRock` 的 ±4° 摇摆降级为「无 squash 时的兜底」（`Quality.low` 分支只跑 rock，不跑粒子）。

**② 喂食 / 洗澡道具飞行**
- Primary：骨头（Graphics 自绘，`COLORS.gold`）从图标位置抛到立绘嘴部，0.45s，弧高 ≈ 立绘宽 × 0.35；到达瞬间 scale `0→1` 归位为「被吃掉」——道具 Node 立即销毁。
- Secondary：到达后 `chew` 两次 scale 脉冲 `(1.06,0.94)`，间隔 0.12s。
- Ambient：洗澡改为 8 颗泡泡（`COLORS.mist` 圆环，半径 8–18 随机）从立绘下缘上飘 140px 并微左漂移，0.9s 错开 0.06s 出生。
- 触屏打断处理：连点同一触点用 `Tween.stopAllByTarget` 先收敛再重放（沿用 `UIButton.bindPress` 已有的写法），避免 tween 叠加把立绘 scale 卡在半空。

**③ 大厅散步带**
- 3 只按 `MotionKit.playStaggerIn` 依次入场（0.06 步长），落位后交给 `PetBehavior` 的五档循环呼吸/摇尾——**这是 ambient，不是新增 infinite 动画**，复用现有档位不新增常驻 tween。
- 点击时：该只 `scale 1→1.05`（0.12）+ 其余两只 `UIOpacity → 150`（0.18）作 staging，然后打开小屋。

### 4.4 与 Web 口径的翻译说明

动效规划/开发两套 Skill 的原生输出是 CSS（`cubic-bezier`、`@media (prefers-reduced-motion: reduce)`）。本工程是 Cocos，规格已全部翻译成 `cc.Tween` 的秒数与内置缓动名；降级策略从「CSS media query」改成工程里已有的 **`Quality.low` 开关**（`MotionKit`、`PageFade`、`playRock` 都吃这个开关），语义等价：去位移、去粒子、保 opacity、时长减半。
